# Cadena de frío de la carne bovina en Chiriguaná, Cesar

Presentación web de la propuesta de mejora integral para la cadena de frío de la planta de beneficio de Chiriguaná, Cesar. Proyecto académico de la asignatura Logística y Cadenas de Suministro (212029), UNAD.

## Contenido

El sitio presenta el problema y sus causas, integra tendencias tecnológicas, ambientales y operacionales, y desarrolla la estrategia de implementación, beneficios, costos, KPI, recursos, riesgos y referencias.

## Abrir el sitio

Abre `index.html` en un navegador. No requiere instalación ni proceso de compilación. El diagrama de Ishikawa se carga desde `assets/ishikawa.png`.

## Publicar en GitHub Pages

1. Sube `index.html`, `README.md` y la carpeta `assets/` a la rama `main`.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/(root)`.
4. Guarda y espera a que GitHub Pages publique el sitio.
